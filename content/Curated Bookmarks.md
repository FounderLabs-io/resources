Links curated from the [Founder Labs community](https://founderlabs.io/community). Each one was shared in our AI links channel and kept here so it doesn't disappear. Every entry says what the link is and why a bootstrapped founder might care.

## AI & Agents

- [Open Generative AI](https://github.com/Anil-matcha/Open-Generative-AI) — Self-hosted, MIT-licensed open-source studio for generating AI images and videos, offering access to 600+ models across 14 studios. *Why it matters:* Gives early founders a free base for an AI media product, though it promotes a paid white-label resale option.
- [rakazo: open-source role-based AI bots you own](https://rakazo.com/) — Open-source app for running role-based AI bots, such as sales outbound, inbox management, and expense matching, from iOS and Android devices. *Why it matters:* Lets founders hand routine work like inbox triage, outreach drafts, and receipts to bots, with drafts held for review.
- [Microduck by Pollen Robotics](https://pollen-robotics.com/microduck/) — A 25 cm open-source biped robot you train yourself with reinforcement learning, starting in a physics simulator. *Why it matters:* At $399 pre-order and open source, it lets hardware-focused founders prototype embodied AI without building a robot from scratch.
- [REA: Reverse Engineer Anything](https://github.com/morluto/rea) — MCP server giving AI agents tools to inspect native binaries, Electron and JavaScript apps, .NET assemblies, and websites locally. *Why it matters:* Lets founders have an agent investigate a feature in an existing app, explain how it works, and rebuild it.
- [obra/superpowers](https://github.com/obra/superpowers) — A composable skills framework and software development methodology that guides coding agents through design, planning, TDD, and subagent-driven implementation. *Why it matters:* Gives coding agents a structured workflow to plan and build autonomously, which could speed up solo development of a product.
- [TradingAgents: Multi-Agents LLM Financial Trading Framework](https://github.com/TauricResearch/TradingAgents) — Open-source multi-agent LLM framework that analyzes markets and produces trading decisions, with backtesting, reports, and multi-provider model support. *Why it matters:* Shows how to build multi-agent LLM pipelines and backtest them, useful for solo builders testing finance-adjacent AI products.
- [leanrea: single-file skill replacing REA's MCP layer for reverse engineering](https://github.com/aicodeking/leanrea) — An 8 KB SKILL.md that tells agents which plain CLI tools to use for each reverse-engineering target, with ready recon commands and no MCP server. *Why it matters:* Self-reported benchmark: 38% less wall time and 35% lower cost than REA at similar accuracy, on one machine.

## Tools & Productivity

- [Lunch Flow: Bank and Investment Sync API](https://www.lunchflow.app/) — API and app that syncs bank, investment, and card transactions and balances daily into budgeting tools like Lunch Money, YNAB, and Google Sheets. *Why it matters:* Replaces manual bank exports for budgeting or investing, and offers a platform API to build bank-connected features.
- [AI Design Skills](https://github.com/elayadesign/ai-design-skills) — Open-source markdown design skills for AI coding tools, including a landing-page skill covering intake, structure, copy, and visual system. *Why it matters:* Lets a bootstrapped founder generate a landing page with conversion copy and a visual system inside Claude Code or Cursor.

## Engineering

- [reverse-api-engineer: Turn websites into APIs](https://reverseapi.dev/) — Open-source CLI that drives a browser, records network traffic as HAR, and has an agent generate a typed API client from it. *Why it matters:* Lets founders turn undocumented site endpoints into local code instead of brittle scraping, running on their machine under MIT license.
- [Tailscale lockdown prompt for Claude Code](https://gist.github.com/alexknowshtml/515c5e741dc4c157d2293f782d15ed41) — A step-by-step Claude Code prompt for auditing and locking down a Tailscale network, replacing default allow-all policy with tags and per-port grants. *Why it matters:* Relevant if your Tailscale devices can reach each other unrestricted; shows how to limit access per port safely.
